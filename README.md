# Марковские цепи и стохастические процессы

Лабораторная работа по дисциплине **«Компьютерное моделирование»**. Исследуется конечная однородная дискретная марковская цепь с тремя состояниями. Аналитический расчет эволюции распределения сравнивается с методом Монте-Карло.

## Модель

Матрица переходов (строки — исходное состояние, столбцы — следующее):

```text
P = [[0.70, 0.20, 0.10],
     [0.15, 0.70, 0.15],
     [0.10, 0.25, 0.65]]
```

Начальное распределение: `p(0) = [1, 0, 0]`. Вероятности удовлетворяют `p(t+1) = p(t) P`. Стационарное распределение определяется из `πP = π`, `Σπᵢ = 1`. В стохастическом расчете каждая из `N` независимых траекторий переходит в следующее состояние по соответствующей строке `P`.

## Установка и запуск

Требуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
python main.py
```

Дополнительные аргументы:

```bash
python main.py --steps 70 --trajectories 12000 --seed 42 --output results
```

Для запуска без автоматического открытия окон или без создания анимации:

```bash
python main.py --no-show
python main.py --no-animation
```

Скорость анимации регулируется параметром `--fps 12`. На сервере без графического окружения файлы сохраняются, но окна не открываются.

## Результаты

После запуска создаются `results/dynamics.png`, `results/accuracy.png`, `results/markov_animation.gif`, `results/dynamics.csv`, `results/accuracy.csv`. Графики и GIF автоматически открываются системным просмотрщиком, если доступно графическое окружение. Первый график показывает теоретические и экспериментальные вероятности и сходимость к стационарному распределению. Второй — среднюю максимальную ошибку и стандартное отклонение по 30 независимым повторам для разных чисел траекторий.

## Воспроизводимость и ограничения

Генератор случайных чисел NumPy инициализируется параметром `seed`. Модель является дискретной, однородной и не описывает реальные физические объекты без дополнительной калибровки. Ошибка Монте-Карло на больших временах не обязана монотонно убывать из-за статистических флуктуаций.
